# Module Anatomy — File Structure Reference

This document provides a detailed breakdown of every file and directory commonly found in a dotfiles module, with real examples from the repository.

---

## Complete Module Structure

```
modules/<name>/
├── Brewfile                 # Required: declare dependencies (tap, brew, cask)
├── Brewfile.lock.json       # Auto-generated: do not edit; ignore in git
├── _setup.zsh               # Optional: install deps, symlink files, init
├── _update.zsh              # Optional: update dependencies
├── _cleanup.zsh             # Optional: remove artifacts on cleanup
├── _info.zsh                # Optional: display module information
├── _zshrc.zsh               # Optional: shell aliases and functions
├── _zprofile.zsh            # Optional: environment variables (login)
├── config/                  # Optional: config files to symlink to ~/.config
├── runcom/                  # Optional: dotfiles to symlink to ~
└── git/                     # Optional: git-specific directory (e.g., git config)
```

## File-by-File Reference

### Brewfile (Required)

**Purpose**: Declare all dependencies that Homebrew should install.

**Location**: `modules/<name>/Brewfile`

**Format**:
```makefile
tap "homebrew/core"
tap "homebrew/bundle"

brew "package-name"
brew "another-package"
cask "app-name"
```

**Rules**:
- Taps must come first
- Brew packages come before casks
- One entry per line
- No comments (lines starting with `#`)

**Example** (`modules/base-cli/Brewfile`):
```makefile
tap "homebrew/bundle"
tap "homebrew/core"

brew "bash"
brew "curl"
brew "coreutils"
brew "jq"
cask "visual-studio-code"
```

**Empty module** (if no dependencies):
```makefile
# No dependencies
```

---

### Brewfile.lock.json (Auto-Generated)

**Purpose**: Lock specific versions of packages; generated by `brew bundle`.

**Location**: `modules/<name>/Brewfile.lock.json`

**Rules**:
- **Do NOT** create manually
- **Do NOT** edit by hand
- **Do NOT** track in git (add to `.gitignore`)
- Generated automatically on first `brew bundle` run

**What it contains**: Exact versions of all installed packages and their dependencies.

### _setup.zsh (Optional)

**Purpose**: Run at setup time (one-time installation, initialization, config file symlinks).

**Location**: `modules/<name>/_setup.zsh`

**Shebang & Bootstrap** (required):
```zsh
#!/bin/zsh
# shellcheck shell=bash

. "$DOTFILES_HOME/bin/_bootstrap.zsh"
```

**Available functions** (from `_bootstrap.zsh`):
- `logging_status "message"` — Print a green status message
- `logging_info "message"` — Print an info message (only if DOTFILES_VERBOSE>=1)
- `logging_debug "message"` — Print debug info (only if DOTFILES_VERBOSE=2)
- `logging_error "message"` — Print error and exit with code 1

**Available helpers** (from `_functions.zsh`):
- `module_brew_bundle <module-name>` — Install from that module's Brewfile
- `brew_bundle <path-to-brewfile>` — Install from a specific Brewfile

**Common pattern**:
```zsh
#!/bin/zsh
# shellcheck shell=bash

. "$DOTFILES_HOME/bin/_bootstrap.zsh"
DIR=$(dirname "$0")

# Install dependencies
module_brew_bundle "$(basename "$DIR")"

# Symlink config files
mkdir -p "$XDG_CONFIG_HOME"
stow -R -d "$DIR" -t "$XDG_CONFIG_HOME" config

logging_status "Setup complete"
```

**Real example** (`modules/git/_setup.zsh`):
```zsh
#!/bin/zsh
# shellcheck shell=bash

DIR=$(dirname "$0")
. "$DOTFILES_HOME/bin/_bootstrap.zsh"

mkdir -p "$DOTFILES_HOME/modules/git/git"

# Substitute email and GPG key into config template
sed "s/EMAILADDRESS/$EMAIL_ADDRESS/g" "$DIR/config.template" >"$DIR/git/config"
sed -i "s/GPGKEY/$GPG_KEY/g" "$DIR/git/config"
cp "$DIR/ignore" "$DIR/git/ignore"

# Link the config
mkdir -p "$XDG_CONFIG_HOME"
ln -s -f "$DIR/git" "$XDG_CONFIG_HOME"

module_brew_bundle "$(basename "$DIR")"
```

### _update.zsh (Optional)

**Purpose**: Update dependencies and refresh configurations.

**Location**: `modules/<name>/_update.zsh`

**Shebang & Bootstrap** (required):
```zsh
#!/bin/zsh
# shellcheck shell=bash

. "$DOTFILES_HOME/bin/_bootstrap.zsh"
```

**Pattern** (update Homebrew packages):
```zsh
#!/bin/zsh
# shellcheck shell=bash

. "$DOTFILES_HOME/bin/_bootstrap.zsh"

logging_status "Updating $(basename "$0" | sed 's/_update.zsh//')"
module_brew_bundle "$(basename "$(dirname "$0")")"
```

**Real example** (`modules/zsh/_update.zsh`):
```zsh
#!/bin/zsh
# shellcheck shell=bash

. "$DOTFILES_HOME/bin/_bootstrap.zsh"

logging_info "Updating zsh packages"
module_brew_bundle "$(basename "$(dirname "$0")")"
```

---

### _cleanup.zsh (Optional)

**Purpose**: Remove module-specific artifacts when cleaning up.

**Location**: `modules/<name>/_cleanup.zsh`

**Shebang & Bootstrap** (required):
```zsh
#!/bin/zsh
# shellcheck shell=bash

. "$DOTFILES_HOME/bin/_bootstrap.zsh"
```

**Pattern** (remove symlinks, cleanup files):
```zsh
#!/bin/zsh
# shellcheck shell=bash

. "$DOTFILES_HOME/bin/_bootstrap.zsh"
DIR=$(dirname "$0")

# Remove symlinked config
rm -f "$XDG_CONFIG_HOME/<module-name>"

# Remove generated files
rm -rf "$DIR/generated/"

logging_status "Cleanup complete"
```

---

### _info.zsh (Optional)

**Purpose**: Display module information or status.

**Location**: `modules/<name>/_info.zsh`

**Shebang & Bootstrap** (required):
```zsh
#!/bin/zsh
# shellcheck shell=bash

. "$DOTFILES_HOME/bin/_bootstrap.zsh"
```

**Pattern**:
```zsh
#!/bin/zsh
# shellcheck shell=bash

. "$DOTFILES_HOME/bin/_bootstrap.zsh"

echo "Module: $(basename "$(dirname "$0")")"
echo "Version: 1.0"
echo "Installed packages: $(brew list --formula | wc -l)"
```

---

### _zshrc.zsh (Optional)

**Purpose**: Shell aliases and functions; sourced every time a new shell starts.

**Location**: `modules/<name>/_zshrc.zsh`

**Shebang** (required):
```zsh
#!/bin/zsh
# shellcheck shell=bash
```

**Note**: Does NOT source `_bootstrap.zsh`; it's a shell extension file, not a command.

**Example** (`modules/base-cli/_zshrc.zsh`):
```zsh
#!/bin/zsh
# shellcheck shell=bash

alias chx="find . -name '*.sh' -exec chmod +x {} \;"
alias reload="exec zsh"
eval "$(thefuck --alias)"
```

**Real example** (`modules/git/_zshrc.zsh`):
```zsh
#!/bin/zsh
# shellcheck shell=bash

alias gs="git status"
alias gd="git diff"
alias ga="git add"
```

---

### _zprofile.zsh (Optional)

**Purpose**: Environment variables and PATH modifications; sourced once at shell startup.

**Location**: `modules/<name>/_zprofile.zsh`

**Shebang** (required):
```zsh
#!/bin/zsh
# shellcheck shell=bash
```

**Note**: Does NOT source `_bootstrap.zsh`.

**Example**:
```zsh
#!/bin/zsh
# shellcheck shell=bash

export JAVA_HOME="/usr/libexec/java_home"
export PATH="$HOME/.local/bin:$PATH"
```

**Real example** (`modules/base-cli/_zshrc.zsh`):
```zsh
export PATH="$HOMEBREW_PREFIX/opt/gnu-sed/libexec/gnubin:$PATH"
```

## Directory Structure

### config/ — Configuration Files

**Purpose**: Configuration files to symlink into `~/.config` (or another location).

**Usage in `_setup.zsh`**:
```zsh
stow -R -d "$DIR" -t "$XDG_CONFIG_HOME" config
```

This symlinks `modules/<name>/config/<filename>` → `~/.config/<filename>`.

**Example** (`modules/zsh/config/`):
```
modules/zsh/config/
└── starship/
    └── starship.toml    →  ~/.config/starship/starship.toml
```

---

### runcom/ — Dotfiles

**Purpose**: Dotfiles to symlink into the home directory (`~`).

**Usage in `_setup.zsh`**:
```zsh
stow -R -d "$DIR" -t "$HOME" runcom
```

This symlinks `modules/<name>/runcom/<filename>` → `~/<filename>`.

**Example** (`modules/zsh/runcom/`):
```
modules/zsh/runcom/
├── .zshrc          →  ~/.zshrc
└── .zprofile       →  ~/.zprofile
```

---

### Module-Specific Directories

Some modules use custom directories for organization. Examples:

**git module** (`modules/git/git/`):
```
modules/git/git/
├── config          (git config)
└── ignore          (global gitignore)
```

Symlinked via `ln -s -f "$DIR/git" "$XDG_CONFIG_HOME"` in `_setup.zsh`.

---

## Template Files

Some modules use `.template` files for customization (substituting variables before use).

**Pattern**:
```zsh
sed "s/PLACEHOLDER/$VARIABLE/g" "$DIR/file.template" >"$DIR/file"
```

**Real example** (`modules/git/config.template`):
```
[user]
    name = Richard Roché
    email = EMAILADDRESS    # Substituted with $EMAIL_ADDRESS
    signingkey = GPGKEY     # Substituted with $GPG_KEY
```

In `_setup.zsh`:
```zsh
sed "s/EMAILADDRESS/$EMAIL_ADDRESS/g" "$DIR/config.template" >"$DIR/git/config"
sed -i "s/GPGKEY/$GPG_KEY/g" "$DIR/git/config"
```

## Complete Real Examples

### Simple Module (Dependencies Only)

**`modules/media/Brewfile`**:
```makefile
tap "homebrew/core"
brew "ffmpeg"
cask "vlc"
```

No hook scripts needed; `module_brew_bundle` handles installation.

### Module with Setup + Dependencies

**`modules/node/`**:
```
modules/node/
├── Brewfile           # brew install node
├── _setup.zsh         # Run npm install -g <packages>
└── _update.zsh        # Update npm packages
```

**`modules/node/_setup.zsh`**:
```zsh
#!/bin/zsh
# shellcheck shell=bash

. "$DOTFILES_HOME/bin/_bootstrap.zsh"
DIR=$(dirname "$0")

module_brew_bundle "$(basename "$DIR")"

# Install global npm packages
npm install -g @angular/cli typescript
```


## Validation Checklist

Before committing a new module:

- [ ] Module directory created: `modules/<name>/`
- [ ] Brewfile exists with valid syntax
- [ ] All `*.zsh` files start with shebang and source `_bootstrap.zsh` (except `_zshrc.zsh`, `_zprofile.zsh`)
- [ ] All `*.zsh` files pass `shellcheck --shell=bash modules/<name>/*.zsh`
- [ ] Module registered in a personality file: `settings/_<personality>-setup.zsh`
- [ ] Setup tested locally: `DOTFILES_VERBOSE=1 dotfiles setup`
- [ ] No `Brewfile.lock.json` in git (add to `.gitignore`)
